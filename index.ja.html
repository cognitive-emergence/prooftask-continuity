ProofTask 継続性ミラー

このディレクトリを使えば、ProofTask に問い合わせることなく、保存した ProofTask の結果記録を誰でも検証できます。オフライン検証ツール、発行者の公開鍵（現在のものと過去のもの）、鍵の履歴が含まれています。ネットワーク接続は一切不要です。

2026-11-24T10:57:34.202Z に https://prooftask.com から作成。 リリース de34ff3587083cdb48dff1a3e9df2d875bd40381。 検証ツールの SHA-256：6f5bcb7f3a7ea7f1ed91558e89e50d7cdb150bc2cabb5927241aa7f346ab1f4b

1. このミラーを確認する

すべてのファイルとその SHA-256 は manifest.json と SHA256SUMS に記載されています。このディレクトリで次を実行してください。

shasum -a 256 -c SHA256SUMS

次に、下の発行者の鍵の指紋を、このミラーとは独立して信頼できる情報源と照合してください。受け取った結果記録に表示されている指紋、ProofTask のソースリポジトリにコミットされた固定鍵（keys/operator-issuers.json はその写し）、または別のミラーです。ミラーの信頼性は、この照合の信頼性を超えません。

2. 保存した結果記録を検証する

Node.js 22 以降と、保存した結果記録ファイル（例：prooftask-result-record-<id>.json または Conformity Package）が必要です。このディレクトリで次を実行してください。

node verifier/verify-conformity.mjs /path/to/prooftask-result-record-ID.json keys/prooftask-trust-bundle.json --text
  • 判定は VERIFIED_WITH_LIMITATIONS, PARTIAL_DISCLOSURE, INDETERMINATE, INVALID のいずれかです。終了ステータス 0 は検証済み（記載された制限を読んでください）、1 は無効、3 は判定不能を意味します。
  • 過去の時点で確認するには、--at=2026-11-21T00:00:00.000Z を追加してください。
  • 結果記録に署名した鍵が現在の信頼バンドルにない場合は、keys/key-history.json でその鍵 ID を探し、keys/prooftask-trust-bundle.json の代わりに、そこに示された過去の信頼バンドル（history/trust-bundles/ 内）を指定してください。
  • 検証ツールに固定されている ProofTask の本番鍵で署名された結果記録は、2 番目の引数なしでも検証できます：node verifier/verify-conformity.mjs RECORD --text
  • ターミナルがない場合は、verifier/prooftask-buyer-record-checker.html（ある場合）をブラウザで開き、結果記録と信頼バンドルを選択してください。

ここでは分からないこと：結果の現在の状態（署名された状態の証明は稼働中のサービスから提供されます。それがない場合、現在の状態は不明と表示されます）、提供していない原本が一致するかどうか、ご自身で承認した範囲を超える会社の権限。署名された履歴と署名は完全に確認されます。
